Управление программами

Сайт работает на GitHub Pages. Он не может сам записывать файлы на GitHub без отдельной защищённой авторизации. Поэтому здесь предусмотрены автосохранение черновика, скачивание готового programs.json и проверка публикации. Сообщение об успешной публикации появится только после фактической проверки файла на сайте.

Посмотреть программы на сайте

После скачивания откройте файл programs.json в репозитории GitHub, замените его содержимое и нажмите Commit changes. Затем нажмите «Проверить публикацию» здесь. Черновик сохраняется только в этом браузере.
