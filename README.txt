БФ «ЯРИЛО». Данные сайта редактируются в /admin/.
Фото, видео, реквизиты, банковские счета и кнопка пожертвования настраиваются через админку.
Сайт работает вместе с Cloudflare Worker yarilo-admin-auth.
Полная инструкция установки находится в README.txt в корне итогового архива.
Изменять отдельные строки JavaScript для настройки пожертвований не требуется.
