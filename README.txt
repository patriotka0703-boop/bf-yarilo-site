КАК ЗАПУСТИТЬ
1. Загрузить СОДЕРЖИМОЕ этой папки в корень домена bf-yarilo.ru.
2. Проверить, что сайт открывается по HTTPS.
3. Добавить сайт в Яндекс Вебмастер и Google Search Console.
4. Передать им адрес: https://bf-yarilo.ru/sitemap.xml
5. Загрузить реальные PDF фонда в раздел отчётности и заменить заглушки ссылками.
6. Регулярно публиковать реальные новости и отчёты с уникальными фото и текстом.

КАК ВКЛЮЧИТЬ ПЛАТЁЖНУЮ КНОПКУ
Откройте script.js.
Найдите:
const DONATION_URL = "";
Вставьте между кавычками официальную платёжную ссылку фонда от банка/эквайринга.
Например:
const DONATION_URL = "https://ваша-платежная-ссылка";
После этого кнопка «Перейти к пожертвованию» станет рабочей.

ВАЖНО
Не размещайте непроверенный номер личной карты как официальный способ пожертвования.
Для полноценного приёма пожертвований лучше использовать официальный эквайринг/платёжную страницу фонда.
